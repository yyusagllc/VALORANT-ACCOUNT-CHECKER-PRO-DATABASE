VALORANT-API.COM — API UÇ NOKTALARI Kaynak:
https://dash.valorant-api.com/ Temel adres: https://valorant-api.com API
sürümü: /v1 HTTP metodu: GET Kimlik doğrulama: Genel içerik API’si için
API anahtarı gerekmez.

NOT Bu dosya valorant-api.com içerik/veri API’sini kapsar. Riot
istemcisinin oturum, mağaza, envanter, maç geçmişi gibi dahili/hesap
bazlı uç noktaları bu API’ye dahil değildir. Skinler, silah uç
noktasının altındaki veriler olarak sunulur; ayrı bir /skins uç noktası
olduğu varsayılmamalıdır.
